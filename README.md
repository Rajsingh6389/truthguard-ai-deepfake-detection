# TruthGuard AI

AI Misinformation & Deepfake Detection System  
Graph-E-Thon 3.0 Hackathon Submission

## Problem

With the rapid advancement of generative AI, deepfake videos and AI-generated misinformation are spreading rapidly across social media platforms. These fake media contents can manipulate public opinion, damage reputations, and cause financial fraud.

Current fact-checking solutions are slow and mostly manual. Therefore, an automated system is required to detect manipulated media and misinformation in real time.

## Solution

TruthGuard AI is an AI-powered platform designed to detect deepfake videos, manipulated images, and fake news articles using computer vision and natural language processing models.

The system analyzes uploaded media and generates a credibility score indicating whether the content is authentic or manipulated.

## Key Features

- Deepfake detection using computer vision models
- Fake news detection using NLP
- Blockchain-based media authenticity verification
- Credibility score generation
- Web dashboard for analysis

## System Workflow

User Upload → AI Detection → NLP Verification → Blockchain Authentication → Credibility Score

## Technology Stack

Frontend: React.js  
Backend: Spring Boot  
AI Models: Python, TensorFlow / PyTorch  
Database: MongoDB / PostgreSQL  
Blockchain: Ethereum
